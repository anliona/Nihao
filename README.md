# Nihao

Интерактивный прототип сервиса, который помогает иностранцам в Китае находить местных помощников для повседневных задач: документов, получения водительских прав, посещения учреждений и других ситуаций, связанных с языковым и культурным барьером.

## Возможности прототипа

- Каталог помощников с фильтрами по городу, языку и категории задачи.
- Профили помощников с описанием услуг и стоимостью.
- Демонстрационное оформление заявки с выбором даты, времени и длительности.
- Просмотр и отмена демонстрационных заявок, интерфейс чата.
- Адаптивная верстка для компьютеров и мобильных устройств.

## Запуск

Скачайте репозиторий и откройте `index.html` в современном браузере. Установка зависимостей и сборка не требуются.

При необходимости можно запустить локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Основная HTML-страница |
| `styles.css` | Стили и адаптивная верстка |
| `app.js` | Данные и интерактивные сценарии прототипа |

Технологии: HTML, CSS, JavaScript без фреймворков и внешних зависимостей.

## Статус

Это демонстрационный прототип, а не действующий сервис. Профили и данные вымышлены. Реальные заявки, сообщения и платежи не отправляются. Сервер, авторизация и платежная система не подключены. Изменения в интерфейсе хранятся в памяти страницы и сбрасываются после перезагрузки.

## Публикация

Файлы расположены в корне и готовы для размещения на статическом хостинге. Для GitHub Pages можно выбрать публикацию из ветки `main`, папка `/ (root)`, в настройках репозитория **Settings → Pages**.
